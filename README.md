# Orbis 

## Dependencies

Orbis is an easy to use, open-source C++ UI rendering framework powered by Direct3D 11 and Vulkan similar to Dear ImGui.

| Library | Purpose | License |
|---|---|---|
| [FreeType](https://github.com/freetype/freetype) | Font loading and glyph rasterization | FTL / GPL-2.0 |
| [HarfBuzz](https://github.com/harfbuzz/harfbuzz) | Advanced text shaping and typography | MIT |
| [stb](https://github.com/nothings/stb) | Image loading and utility functions | MIT / Public Domain |
| [spdlog](https://github.com/gabime/spdlog) | Logging and diagnostics | MIT |
